## ⚠️ Если видите ошибку SSL:

1. **Скопируйте и вставьте URL вручную:**
   ```
   http://89.169.182.9:3003
   ```

2. **Или нажмите "Дополнительно" → "Перейти на сайт"**

3. **Или добавьте исключение безопасности**
