## 🎯 ИНСТРУМЕНТЫ DASHBOARD ДЛЯ DEV → STAGING → PROD

### 🔄 WORKFLOW КНОПКИ (ОСНОВНЫЕ):

#### 1. 💾 "Фиксация Development"
- **API:** `/api/deployment/workflow/sync-development`
- **Функция:** `syncDevelopment()`
- **Что делает:**
  - Переходит в Development контур
  - Инициализирует Git репозиторий (если нужно)
  - Переключается на develop ветку
  - Добавляет все изменения в staging
  - Создает коммит с изменениями
  - Отправляет изменения в GitHub
  - Запускает тесты в development

#### 2. 🧪 "Тестирование в Staging"
- **API:** `/api/deployment/workflow/test-staging`
- **Функция:** `testInStaging()`
- **Что делает:**
  - Копирует состояние Production в Staging
  - Применяет изменения из develop ветки
  - Генерирует SQL миграции
  - Запускает тесты в staging
  - Проверяет работоспособность

#### 3. 🚀 "Деплой в Production"
- **API:** `/api/deployment/workflow/deploy-production`
- **Функция:** `deployToProduction()`
- **Что делает:**
  - Создает полный бэкап Production
  - Проверяет существование develop ветки
  - Выполняет merge develop → main
  - Применяет миграции
  - Перезапускает Production сервер

#### 4. ⚡ "Полный Workflow"
- **API:** `/api/deployment/workflow/full`
- **Функция:** `performFullWorkflow()`
- **Что делает:**
  - Выполняет все этапы последовательно
  - Development → Staging → Production
  - Полный отчет о выполнении

---

### 🔧 ВСПОМОГАТЕЛЬНЫЕ ИНСТРУМЕНТЫ:

#### 5. 🔍 "Сравнить схемы БД"
- **API:** `/api/database/compare-schemas`
- **Функция:** `compareSchemas()`
- **Что делает:**
  - Сравнивает структуру prod и dev БД
  - Выявляет различия в таблицах и колонках
  - Создает отчет о различиях

#### 6. 💾 "Бэкап БД prod"
- **API:** `/api/database/backup`
- **Функция:** `createBackup()`
- **Что делает:**
  - Создает резервную копию продакшн БД
  - Проверяет целостность бэкапа
  - Сохраняет с временной меткой

#### 7. 📋 "Залить базу prod → staging"
- **API:** `/api/database/copy-prod-to-staging`
- **Функция:** `copyProdToStaging()`
- **Что делает:**
  - Копирует базу данных из production в staging
  - Опционально копирует медиафайлы
  - Перезаписывает staging базу

#### 8. 🖥️ "Запустить сервер"
- **API:** `/api/deployment/environments/start`
- **Функция:** `startEnvironment()`
- **Что делает:**
  - Переключает между контурами
  - Запускает systemd сервисы
  - Обеспечивает безопасность production

---

### 🔄 ОТКАТЫ (БЕЗОПАСНОСТЬ):

#### 9. 🔄 "Откат Staging"
- **API:** `/api/deployment/workflow/rollback-staging`
- **Функция:** `rollbackStaging()`
- **Что делает:**
  - Откатывает staging к состоянию production
  - Восстанавливает предыдущее состояние

#### 10. 🔄 "Откат Production"
- **API:** `/api/deployment/workflow/rollback-production`
- **Функция:** `rollbackProduction()`
- **Что делает:**
  - Откатывает production к предыдущему коммиту
  - Критическая операция с подтверждением
