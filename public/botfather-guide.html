🤖 ИСПРАВЛЕНИЕ ЧЕРНОГО ЭКРАНА

Настройка Menu Button в BotFather

🚨 ПРОБЛЕМА ДИАГНОСТИРОВАНА

На ПК работает: Telegram Web корректно обращается к серверу

На мобильном черный экран: Telegram бот НЕ обращается к серверу

Причина: Неправильно настроен Menu Button в BotFather

✅ РЕШЕНИЕ

Нужно правильно настроить Menu Button в BotFather для мобильных устройств

📋 ПОШАГОВАЯ ИНСТРУКЦИЯ:

ШАГ 1: Откройте BotFather

1. Откройте Telegram

2. Найдите @BotFather

3. Нажмите /start

ШАГ 2: Выберите ваш бот

1. Отправьте команду /mybots

2. Выберите DeliveryVLG из списка

ШАГ 3: Настройте Menu Button

1. Нажмите "Bot Settings"

2. Нажмите "Menu Button"

3. Введите следующие данные:

Text (Название): 🍽️ Заказать еду
URL: https://www.deliveryvlg.xyz:3443/app

⚠️ КРИТИЧЕСКИ ВАЖНО:

URL должен быть ТОЧНО: https://www.deliveryvlg.xyz:3443/app

БЕЗ слэша в конце, БЕЗ дополнительных параметров!

ШАГ 4: Проверьте настройки

1. После сохранения вернитесь в чат с ботом

2. Нажмите /start

3. Внизу должна появиться кнопка "🍽️ Заказать еду"

ШАГ 5: Альтернативный способ (если не работает)

Если Menu Button не работает, используйте команду:

/setmenubutton
Выберите бот: DeliveryVLG
Text: 🍽️ Заказать еду
URL: https://www.deliveryvlg.xyz:3443/app

🔧 ДОПОЛНИТЕЛЬНЫЕ НАСТРОЙКИ:

Настройка команд бота

Также рекомендуется настроить команды:

/setcommands
start - 🚀 Запустить приложение
menu - 🍽️ Открыть меню
help - ❓ Помощь

Настройка описания

Обновите описание бота:

/setdescription
🍽️ Быстрая доставка вкусной еды в Волгограде
📱 Заказывайте через удобное приложение
🚚 Доставка за 30 минут

🎯 ПРОВЕРКА РЕЗУЛЬТАТА:

✅ Если все настроено правильно:

1. В мобильном Telegram появится кнопка "🍽️ Заказать еду"

2. При нажатии откроется приложение (НЕ черный экран)

3. В логах сервера появятся запросы от мобильного Telegram

🚨 Если проблема остается:

1. Проверьте, что URL точно https://www.deliveryvlg.xyz:3443/app

2. Попробуйте удалить и создать Menu Button заново

3. Проверьте, что SSL сертификат валиден

4. Обратитесь к разработчику для проверки логов
