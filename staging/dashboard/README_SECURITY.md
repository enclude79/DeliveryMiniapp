# 🔒 Безопасность Dashboard

## 📋 Обзор защиты

Dashboard теперь защищен от основных типов атак:

### ✅ Реализованные меры безопасности:

1. **JWT Аутентификация**
   - Токены истекают через 24 часа
   - Все API endpoints защищены
   - Автоматическая проверка токенов

2. **Rate Limiting (Защита от брутфорса)**
   - Логин: максимум 5 попыток за 15 минут
   - API: максимум 100 запросов за 15 минут
   - API endpoints: максимум 200 запросов за 5 минут

3. **Helmet Security Headers**
   - Content Security Policy
   - Защита от XSS атак
   - Безопасные заголовки HTTP

4. **Оптимизированная производительность**
   - Интервал обновления логов: 30 секунд
   - Настраиваемые параметры

## ⚠️ Важные замечания:

1. **Используйте HTTP, не HTTPS**
   - Dashboard работает только по HTTP
   - Если браузер пытается открыть HTTPS, он автоматически перенаправит на HTTP

2. **При ошибке SSL в браузере:**
   - Введите URL вручную: `http://89.169.182.9:3003`
   - Или нажмите "Дополнительно" → "Перейти на сайт"

3. **Rate Limiting:**
   - Если превышен лимит попыток входа, подождите 15 минут
   - Если превышен лимит API запросов, подождите 5-15 минут

## 🔧 Настройка параметров безопасности

Все параметры можно настроить в файле `config.js`:

```javascript
// Rate limiting настройки
rateLimitWindowMs: 15 * 60 * 1000, // 15 минут
rateLimitMax: 100, // максимум 100 запросов
loginRateLimitWindowMs: 15 * 60 * 1000, // 15 минут
loginRateLimitMax: 5 // максимум 5 попыток входа
```
