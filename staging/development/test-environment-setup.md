## 📱 Доступ к Test Environment:

### Android/iOS:
1. Быстро тапните 10 раз по Settings (Настройки)
2. Выберите Accounts → Login to another account → Test
3. Создайте тестовый аккаунт

### Telegram Desktop:
1. Откройте боковое меню
2. Удерживайте Shift + Alt и кликните правой кнопкой на "Add Account"
3. Выберите "Test Server"

### macOS:
1. Быстро кликните 10 раз по иконке Settings
2. Удерживайте Cmd + кликните "Add Account"

## 🤖 Создание тестового бота:
1. В тестовом окружении найдите @BotFather
2. Создайте НОВОГО бота (отдельного от продакшна)
3. Настройте для него ваш development URL

## ⚡ Преимущества:
- ✅ Можно использовать HTTP (не только HTTPS)
- ✅ Можно использовать IP адреса
- ✅ Полная изоляция от продакшна
- ✅ Удобная отладка
